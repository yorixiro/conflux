## 历史资料

`work-orders/`、`CONFLUX_ROLE_SETTINGS.md` 及部分上游模块笔记是历史实现/验证记录，**不能作为现在强制执行的工单或 UI 规则**。`open-source/` 只保留两份底层存储证据。删除的过期交接、审计和重复发布门槛仍可从 Git 历史找回。

功能完成度、代码实际运行状态都以当前 `conflux-dev` 为准。相关实现改变时更新已有文件，不为普通小改新建文档。
