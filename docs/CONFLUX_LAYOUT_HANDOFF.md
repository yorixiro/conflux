# 侧栏与主页：给 Claude 的结构交接

本轮负责结构和既有功能接线。气泡、背景、贴纸等外观继续接第二版美化，不另画一套。

- 侧栏顶部按顺序放「个人资料」「对话库」，默认打开对话库。
- 个人资料读取当前角色，通往现有资料编辑页，保留角色切换和创建。
- 对话库集中放新建、搜索、置顶和普通对话；沿用原有创建、置顶、重命名和删除动作。
- 搜索复用原有正文匹配函数和存储读取接口；标题、旧消息和附件名称都能查，摘录能跳到原消息。
- 手机抽屉与桌面共用侧栏，不复制两套功能。
- 主页首排固定：时钟宽度 45%，待办 55%；下一排整行日历，再下一排小功能网格。
- 时钟显示设备时间。待办、日历只占位，明确标「预留」。小功能连接已有入口。
- 窄屏保持首排比例；小功能宽屏三列、手机两列。各排左右对齐。

修改外观时，保留 `ConfluxHome`、`DesktopAppSidebar` 的区域顺序、尺寸比例与动作接口。相关样式在 `ConfluxHome.css`、`ConfluxSidebar.css`。

检查：类型检查、生产构建及相关搜索检查；浏览器用虚构数据核对手机横竖屏、桌面布局和侧栏操作。此前运行的整套回归属于北极星原仓库，不是这次新增的测试。

未验收：真实模型接口、用户已安装的 PWA、Android 真机。没有数据格式变更。
