# 侧栏与主页：给 Claude 的结构交接

本轮负责结构和既有功能接线。气泡、背景、贴纸等外观继续接第二版美化，不另画一套。

- 侧栏顶部按顺序放「个人资料」「对话库」，默认打开对话库。
- 个人资料首屏展示当前角色头像、名字、简介和用户称呼，直接放「编辑人设 / 切换角色 / 新建角色」。
- 新建角色直接创建手动模板并打开既有编辑页；「AI 生成人设」收在「更多创建方式」里，不自动调用模型。
- 切换角色复用原有进入角色对话动作，打开其已有对话，没有时才新建空对话，保留旧对话。
- 「模型线路」直达既有供应商设置；「记忆设置」直达当前角色的记忆页，不自动启用摘要或向量。
- 对话库集中放新建、搜索、置顶和普通对话；沿用原有创建、置顶、重命名和删除动作。
- 搜索复用原有正文匹配函数和存储读取接口；标题、旧消息和附件名称都能查，摘录能跳到原消息。
- 手机抽屉与桌面共用侧栏，不复制两套功能。
- 手机和平板聊天页左上角依次为返回首页、打开侧栏，右上角「＋」沿用当前角色的新建对话动作。
- 主页最上方为整行时钟展示面板，高度约视口的 42%（最小 280px、最大 520px）。时间和日期放在左下方，上方留给后续装饰。
- 时钟面板下方一排等宽放待办与日历，再下一排小功能网格，各排左右对齐。
- 时钟显示设备时间。待办、日历只占位，明确标「预留」。小功能连接已有入口。
- 窄屏仍保持待办与日历并列；小功能宽屏三列、手机两列。
- 设置页依次为「聊天与模型 / 外观 / 数据与备份 / 扩展功能 / 语言与帮助」。扩展功能默认折叠，集中收纳工具箱、MCP、生图、请求路由和可用的桌面目录入口。所有入口沿用既有设置动作，不改变配置和数据。
- 每条已完成的普通聊天消息下方显示时间及紧凑 Token 入口；点击在数字下方弹出约 260px 宽的小卡片，左侧消息左对齐、右侧消息右对齐。下方不足才翻到上方，并限制在聊天滚动区内，避开顶栏和输入区。各项用量按行排列，说明默认收起，背景不加遮罩色；点空白、关闭按钮或 Escape 收起。读取该条保存的输入、输出、缓存和推理用量，未记录字段明确显示「未记录」，接口返回的 0 保留；完全没有用量时仅提示「这条消息没有记录 Token 用量」，不铺七行空数值。模型标题处不重复摆放 Token 数字，输入区维持原布局。

修改外观时，保留 `ConfluxHome`、`DesktopAppSidebar` 的区域顺序、尺寸比例与动作接口。相关样式在 `ConfluxHome.css`、`ConfluxSidebar.css`。

检查：类型检查、生产构建及相关搜索检查；浏览器用虚构数据核对手机横竖屏、桌面布局和侧栏操作。此前运行的整套回归属于北极星原仓库，不是这次新增的测试。

未验收：真实模型接口、用户已安装的 PWA、Android 真机。没有数据格式变更。
