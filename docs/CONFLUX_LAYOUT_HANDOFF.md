# 聊天侧栏与主页结构交接

本轮只整理结构和接通既有功能。聊天区第二版的气泡、背景、贴纸等美化继续使用原稿；没有重新创作这套美术，也没有把截图当成可交互页面导入。

## 固定布局

- 侧栏顶部两项，顺序为「个人资料」「对话库」，默认打开对话库。
- 个人资料显示当前角色的真实资料，并通往既有资料编辑页；保留角色切换和创建入口。
- 对话库集中放置新建对话、聊天记录搜索、置顶对话和普通对话列表。既有重命名、取消置顶和删除确认继续可用。
- 手机聊天顶栏打开侧栏抽屉，桌面使用常驻侧栏，两端复用同一个组件。
- 主页首排固定两栏：时钟占可分配宽度的 45%，待办占 55%；窄屏也保持这个顺序与比例。
- 下一排日历占整行，左右边缘与上排对齐；再下一排是小功能网格，宽屏三列、手机两列。
- 时钟显示设备本地时间；待办与日历本轮只预留结构，明确标记「预留」，未制造待办或日程数据。
- 小功能网格连接已有的档案、角色资料、项目、代码、图片和群组；IB 生活模块仍按迁移清单逐项接入。

## 数据与搜索

- 置顶、创建、重命名仍调用原聊天动作，不另存一套会话。
- 搜索既匹配标题，也读取当前角色范围内的聊天正文与附件名称；不是只筛选最近摘录。
- 未加载的正文通过既有只读接口读取，最多四个并发；输入防抖，旧搜索取消后不继续排队。
- 读取失败单独提示，不能冒充完整的「无结果」。点击内容摘录定位原消息。
- 没有迁移、覆盖或清理用户存储，没有更改模型路由、聊天请求引擎或安装端口。

## 验证

- `npm ci --ignore-scripts --no-audit --no-fund`。
- `npm run verify`：主/额外/Worker 类型检查、492 个测试文件中的 3111 项测试、生产构建全部通过。
- 新增搜索测试覆盖：旧消息正文、角色范围隔离、附件名称、读取失败、并发上限及取消过期搜索。
- 一次性 Chromium 测试环境，使用虚构角色与对话；检查 320×568、390×844、844×390、1440×900 四种尺寸的卡片比例、对齐、溢出、资料切换、置顶分组、全文搜索、原消息跳转和抽屉关闭。
- 未对真实账户调用模型接口；未在用户手机、已安装 PWA 或 Android APK 上做实际验收。

回退可撤销本轮提交；本轮没有数据格式变更。
