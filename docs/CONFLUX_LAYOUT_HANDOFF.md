# 对话入口、侧栏与主页：结构交接

本轮负责结构和既有功能接线。气泡、背景、贴纸等外观继续接第二版美化，不另画一套。

- 桌面侧栏与手机、平板的头像抽屉共用「个人资料 / 对话库」双页签；桌面默认打开对话库，手机默认打开当前 AI 资料，页签可直接切换。
- 个人资料展示当前聊天 AI 的头像、名字和简介，提供「角色设置」。资料按当前对话的归属角色读取，浏览全部聊天记录或编辑别的角色时，不改成用户身份或其他 AI。
- 资料下方放一张紧凑月历，星期一开始，可翻月、标记今天并回到本月。只读设备日期、维护显示月份，不接入日程存储或模型请求；结构与样式分别为 `SidebarCalendar.tsx`、`ConfluxSidebar.css`。
- 通讯录位于侧栏「对话库」内，沿用原角色和聊天操作。手机和平板通过聊天顶部 AI 头像打开侧栏，切到「对话库」即可访问搜索、聊天记录和通讯录，不再叠加独立对话主页。「AI 生成人设」仍在「更多创建方式」里，手动新建不会请求模型。
- 通讯录中点头像/名字进入聊天，右侧齿轮编辑对应角色；手机选中角色后收起侧栏，返回原聊天页。资料与本地月历留在侧栏「个人资料」，不改变角色或聊天数据。
- 档案只显示对话档案，通讯录不再作为档案分类。角色设置沿用 info 编辑实现，但在导航上归于聊天；主页原通讯录按钮改为当前聊天 AI 的「角色设置」。
- 切换角色复用原有进入角色对话动作，打开其已有对话，没有时才新建空对话，保留旧对话。
- 刷新后首次打开后台对话时，沿用现有正文延迟读取，同时回填该记录已保存的草稿；读取期间新输入的草稿优先，不能用目录占位的空串覆盖原草稿。此修复不改变存储格式、历史或模型请求。
- 全局模型线路保留在设置页；角色自己的线路、记忆从角色设置进入，不自动启用摘要或向量。
- 对话库顶部显示当前角色并保留角色设置快捷入口；手机抽屉使用同一套对话列表、搜索、置顶、重命名、删除和通讯录动作。
- 角色页把资料与人设合在一起，API 与模型紧随其后，另保留记忆、主题和主动。头像直接在资料页改，API 页可编辑所选线路的地址和 Key，并单独保存角色模型。内置小助手标明固定身份并可直接新建普通角色。IB 对照、作用域与尚未接通部分见 `CONFLUX_ROLE_SETTINGS.md`。
- 搜索复用原有正文匹配函数和存储读取接口；标题、旧消息和附件名称都能查，摘录能跳到原消息。
- 手机抽屉和桌面侧栏复用 `DesktopAppSidebar` 的现有对话、搜索、角色和管理动作；没有第二套领域状态或读写接口。
- 手机和平板聊天页左上角保留返回首页和打开当前 AI 侧栏的入口；右上角「＋」仍是当前角色的新建对话动作。底部「对话」切回原聊天页，不新增独立的对话主页。
- 主页最上方为整行时钟展示面板，高度约视口的 42%（最小 280px、最大 520px）。时间和日期放在左下方，上方留给后续装饰。
- 时钟面板下方一排等宽放待办与日历，再下一排小功能网格，各排左右对齐。
- 时钟显示设备时间。待办、日历只占位，明确标「预留」。小功能连接已有入口。
- 窄屏仍保持待办与日历并列；小功能宽屏三列、手机两列。
- 设置页依次为「聊天与模型 / 外观 / 数据与备份 / 扩展功能 / 语言与帮助」。扩展功能默认折叠，集中收纳工具箱、MCP、生图、请求路由和可用的桌面目录入口。所有入口沿用既有设置动作，不改变配置和数据。
- 模型线路将「默认线路」与「待配置 / 待密钥 / 已填写」分开显示，避免选中线路后掩盖缺项。详情首先显示缺少的接口地址、Key 或模型名及自动保存说明；「完成」关闭并返回原页面。能力开关、备用看图、诊断和真实连接测试放在默认折叠的可选区，复制和删除线路放在末尾的管理区；测试明确提示可能计费，填写和关闭页面不会自动测试。角色专属线路仍由原角色设置管理，不新增模型路由或存储实现。
- 每条已完成的普通聊天消息下方显示时间及紧凑 Token 入口；点击在数字下方弹出约 260px 宽的小卡片，左侧消息左对齐、右侧消息右对齐。下方不足才翻到上方，并限制在聊天滚动区内，避开顶栏和输入区。各项用量按行排列，说明默认收起，背景不加遮罩色；点空白、关闭按钮或 Escape 收起。读取该条保存的输入、输出、缓存和推理用量，未记录字段明确显示「未记录」，接口返回的 0 保留；完全没有用量时仅提示「这条消息没有记录 Token 用量」，不铺七行空数值。模型标题处不重复摆放 Token 数字，输入区维持原布局。

- 普通消息用「⋯」打开约 250px 宽的操作卡片，跟随消息并避开顶栏及输入区。自己的消息在时间、Token 旁放入口，也支持长按和右键；助手保留文字选择。双方都能复制和删除，自己的消息沿用「编辑并重发」，回答沿用本地编辑、从此分支和重新生成。工具回执不单独提供删除入口；删除回答时明确确认它关联的回执，保留其他消息及已保存文件、卡片。生成中不提供修改或删除，重发、重新生成确认后才请求模型，并说明后续记录替换及接口计费。

修改外观时，保留 `ConfluxHome`、`DesktopAppSidebar` 的区域顺序、尺寸比例与动作接口。手机抽屉的样式在 `ConfluxSidebar.css`，底部入口在 `MobileBottomNavigation.tsx`；其他相关样式在 `ConfluxHome.css`，消息操作在 `chat-actions-tools.css`。

2026-10-24 对话入口调整的历史验收：类型检查、生产构建、5 个现有测试文件共 68 项通过；当时的独立对话主页已在 2026-10-25 撤回，故历史浏览器验证不代表撤回后版本的 UI 验收。撤回后类型检查与 2 个现有导航测试文件（16 项）通过；未新增数据格式或复制业务逻辑。

未验收：真实模型接口、用户已安装的 PWA、Android 真机。没有数据格式变更。
