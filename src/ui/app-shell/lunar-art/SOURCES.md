The lunar disc uses the LROC color mosaic and LOLA elevation data distributed in the [CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/). Credit: NASA's Scientific Visualization Studio (Ernie Wright), LROC and LOLA instrument teams. This project projected the near side, shaded terrain normals, and graded the result. The foreground profile samples the same elevation map along the equator. The background dust plate is procedural.
